# Rock, Paper, Scissors Game in C++ 🎮

A console-based Rock, Paper, Scissors game built with C++. This project was created as part of my learning journey to master C++ fundamentals, loops, functions, and input validation.

## Features
- **Input Validation:** Prevents program crashes if the user enters letters or invalid text using `cin.fail()`.
- **Multiple Rounds:** Allows the user to choose and play as many rounds as they want.
- **Score Summary:** Keeps track of wins, losses, and draws, and announces the final match winner.
- **Replay Option:** Lets you play again without restarting the program.

## Technologies Used
- **Language:** C++
- **Concepts Applied:** `enum`, functions, loops (`do-while`, `for`), conditional statements, and error handling.

## How to Run
1. Clone or download the repository.
2. Open `main.cpp` in your C++ environment (e.g., Cxx app on mobile).
3. Compile and run the code.
